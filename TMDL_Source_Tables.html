TMDL Source Tables

Paste one or more .tmdl files. Every partition and expression source is read, the SQL inside the M string is decoded, and each table or view after FROM, JOIN or a comma list is collected. For Analysis Services sources (AnalysisServices.Database with a DAX EVALUATE query) the model tables used by the DAX are collected. M navigation steps like {[Schema=…,Item=…]} are picked up too.

Detection is lexical, not a full SQL parse. CTE names, subqueries, TABLE(…) / JSON_TABLE(…) style functions and the FROM inside EXTRACT / TRIM / SUBSTRING are skipped. Dynamic SQL that concatenates a non-text parameter shows as {Param} in the name. DAX detection is lexical too: it finds 'Table'[Column], Table[Column] and tables passed as the first argument of functions such as FILTER or VALUES; DAX variables and measure references are ignored, and a DAX table is shown as SourceModel.Table. Nothing leaves your browser.
